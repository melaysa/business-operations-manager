# Business Operations Manager

## Projektbeschreibung



Eine webbasierte Verwaltungssoftware für einen
fiktiven Dienstleistungsbetrieb.

Die Anwendung soll Kunden, Aufträge und Termine
übersichtlich verwalten und Arbeitsabläufe vereinfachen.



## Geplante Funktionen

* \[ ] Kundenverwaltung
* \[ ] Auftragsverwaltung
* \[ ] Auftragsstatus verwalten
* \[ ] Terminverwaltung
* \[ ] Dashboard mit Kennzahlen



## Verwendete Technologien

* Python
* Flask
* SQLite
* HTML
* CSS
* Git
