# Business Operations Manager

Eine webbasierte Verwaltungssoftware für einen fiktiven Dienstleistungsbetrieb. Die Anwendung hilft dabei, Kunden, Aufträge und dazugehörige Termine zu verwalten.

## Funktionen

- [x] Kunden anlegen, bearbeiten und löschen
- [x] Aufträge Kunden zuordnen und verwalten
- [x] Auftragsstatus ändern
- [x] Termine zu Aufträgen planen und anzeigen
- [ ] Dashboard mit Kennzahlen

## Verwendete Technologien

- Python und Flask
- SQLite
- HTML und CSS
- Git

## Starten

1. Abhängigkeiten aus `requirements.txt` installieren.
2. Die Anwendung mit `python app.py` starten.
3. Im Browser `http://127.0.0.1:5000` öffnen.

Beim Start wird die SQLite-Datenbank angelegt, falls sie noch nicht existiert.

## Projektstatus

Die Kunden-, Auftrags- und Terminverwaltung ist als Demo umgesetzt. Das Dashboard ist noch offen.
